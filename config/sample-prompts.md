# Sample coding prompts (local eval)

Used by `.\scripts\Eval-CodingModel.ps1`. Keep prompts short so small local models finish quickly.

1. Write a PowerShell function `Reverse-String` that reverses its input string. Return only the function.
2. Explain in two sentences what a Python generator is.
3. Fix this bug: `for i in range(5) print(i)` — return only the corrected line.
4. Write a TypeScript type for a User with id:number and name:string. Return only the type.
5. Given array [3,1,2], write JavaScript to sort ascending without mutating the original. Return only the code.
